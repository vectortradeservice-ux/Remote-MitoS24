# Camera Cast

แอปเดียว 2 โหมด: **มือถือ (S24 Ultra)** ส่งภาพหน้าจอแอปกล้อง Samsung → **แท็บเล็ต (Xiaomi Pad Mini)** ดูภาพ แตะโฟกัส/ปรับความสว่าง และกดชัตเตอร์

## ได้ไฟล์ APK
**วิธี A – GitHub Actions (ไม่ต้องลง Android Studio):** push โฟลเดอร์นี้ขึ้น GitHub → แท็บ Actions → Build APK → ดาวน์โหลด `CameraCast-apk` (ได้ `app-debug.apk`)

**วิธี B – Android Studio:** เปิดโฟลเดอร์นี้ → Build > Build APK(s)

ติดตั้งไฟล์เดียวกันลงทั้งมือถือและแท็บเล็ต

## วิธีใช้
1. มือถือ: เปิด Mobile Hotspot ย่าน 5 GHz แล้วให้แท็บเล็ตต่อ Wi-Fi นั้น (ต่อตรง = delay ต่ำสุด)
2. มือถือ: เปิดแอป → "เครื่องนี้คือมือถือ" → เปิด Accessibility → เริ่มส่งภาพ (เลือก **ทั้งหน้าจอ**) → จะเด้งไปแอปกล้อง
3. แท็บเล็ต: เปิดแอป → "เครื่องนี้คือแท็บเล็ต" → กด "ใช้ IP ของ Hotspot" → ใส่ PIN ที่เห็นบนมือถือ → เชื่อมต่อ
4. แตะ/ลาก/กดค้างบนภาพได้เหมือนแตะมือถือโดยตรง (โฟกัส ปรับความสว่าง สลับโหมด กดชัตเตอร์) ผลของการลากจะทำงานหลังปล่อยนิ้ว
5. ปุ่ม ↻ มุมขวาบน = หมุนภาพทีละ 90° (จำค่าไว้) / ✕ = ตัดการเชื่อมต่อ / หมุนตัวแท็บเล็ตเป็นแนวตั้งได้ ภาพจะใหญ่ขึ้น

## ปรับ delay / ความคม
`ScreenCastService.kt` ค่า `MAX_SIDE`, `BITRATE`, `FPS` — ลด MAX_SIDE (เช่น 1280) เพื่อ delay ต่ำลงอีก

## หมายเหตุ
- ขนาดไฟล์/คุณภาพรูปและวิดีโอจริงยังบันทึกในเครื่องมือถือเต็มคุณภาพ ภาพบนแท็บเล็ตเป็นภาพบีบอัดไว้ดูเฟรมเท่านั้น
- โค้ดนี้ยังไม่เคยคอมไพล์/ทดสอบกับเครื่องจริง อาจต้องแก้เล็กน้อยเมื่อบิลด์ครั้งแรก
